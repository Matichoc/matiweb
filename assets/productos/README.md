## Reglas para que se vean bien

- **Cuadradas (1:1)**, de al menos **800 × 800 px**. La tienda las muestra cuadradas; si no lo son, se recortan los bordes, así que deja el producto al centro.
- Formato **.jpg** (también sirve .webp). Peso máximo **300 KB** por foto; si pesa más, pásala por [squoosh.app](https://squoosh.app) o reduce la calidad al 80 %.
- Nombre en **minúsculas, sin espacios ni tildes** (usa `_` en vez de espacio), tal cual la tabla.
- Fondo limpio y buena luz natural. Que se vea el producto, no las manos ni el mesón.
- Usa solo **fotos propias**. Si aparece una persona (sobre todo un niño), debe haber dado su permiso.

## Cómo subirlas

1. En GitHub, entra a esta carpeta (`assets/productos`).
2. **Add file → Upload files** y arrastra las fotos.
3. Abajo, **Commit changes**.
4. Avísame con "fotos subidas": reviso los nombres, las conecto a la tienda y dejo las de imgur solo como respaldo para los productos que aún no tengan foto propia.

Subirlas aquí **no cambia nada del sitio** hasta que yo las conecte, así que no hay riesgo de que algo se rompa.
